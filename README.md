## Selected projects

- [gore](https://github.com/figurophobia/gore): turns any Godot game (PCK/EXE) into an openable Godot project, with automatic encryption key recovery
- [Milk-Filter-Online](https://figurophobia.github.io/Milk-Filter-Online/): web app that applies the visual style of *Milk inside a bag of milk* to your photos
- [Milk-Filter-Mobile](https://github.com/figurophobia/Milk-Filter-Mobile): the same idea as an Android app, written in Kotlin
- [gixenpy](https://github.com/figurophobia/gixenpy): unofficial Python client for Gixen.com, published on PyPI
- [YTMSplitter](https://github.com/figurophobia/YTMSplitter): splits a YouTube Music liked-songs playlist into style-based playlists
